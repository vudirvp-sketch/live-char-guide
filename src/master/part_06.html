CoT (цепочка рассуждений)

CoT (цепочка рассуждений) — техника задания внутреннего процесса: модель проговаривает шаги персонажа перед тем, как ответить. Нужен не всем: CoT — дополнительный слой сверх телесности, а не её замена.

Что добавляет CoT:

  • 4 уровня сложности — от простых внутренних рассуждений до структурированного анализа
  • CoT-якоря — триггер → [внутренний процесс] → реакция → цена
  • XML-синтаксис — <processus_analysium> для структурированных размышлений

CoT-якорь строится на двух опорах: сенсорный триггер (что персонаж замечает) и скрытое напряжение SPINE (что за этим стоит). Без второй опоры внутренний монолог превращается в пересказ сцены.

ПРАВИЛО: не более 2–3 CoT-якорей на карточку. Перегрузка ломает внешнюю реакцию: модель тратит ответ на внутренний монолог вместо действий.

Почему ограничение:

  • Токены: Каждый CoT-якорь добавляет ~50-80 токенов внутреннего процесса на ответ
  • Баланс: При 3+ CoT-якорях модель тратит >50% ответа на внутренний монолог вместо действий
  • Качество: Перегрузка снижает качество внешней реакции — модель "забывает" реагировать физически
  • Утомляемость: Читатель устаёт от бесконечного внутреннего монолога

Как выбрать 2-3 якоря:

  • Выберите 2-3 ключевых триггера, где внутренний процесс критичен
  • Остальные триггеры — обычные якоря без CoT
  • Пример: CoT для GHOST-триггеров, обычные якоря для бытовых реакций

Зачем нужен CoT

  • Глубина реакции: Модель понимает, ПОЧЕМУ персонаж реагирует так
  • Связь с призраком (GHOST): Внутренний процесс связывает триггеры с травмой
  • Уровни сложности: Tier 0 (только телесность) → Tier 3 (полный XML); какой уровень держит модель — в таблице ниже.

Уровни CoT (Tiers)

CoT имеет четыре уровня. Tier 0 — без отдельного блока: телесность (состояние → тело → сенсор → речь) уже работает как микро-цепочка рассуждений — это baseline, а не «модель не думает». Tier 1+ добавляет явный [INTERNAL]-блок поверх телесности. Tier 3 — полный XML-процесс для API. Выбор уровня зависит от размера модели и нужной глубины; CoT не заменяет телесность.

Прогрессия Chain of Thought

CoT не обязателен — Tier 0 работает для всех моделей. На Tier 0 модель не «не думает» — Протокол телесности (State → Body → Sensor → Speech) действует всегда как микро-цепочка рассуждений.действует всегда как микро-цепочка рассуждений. CoT (Tier 1+) добавляет отдельный [INTERNAL]-блок как явный внутренний монолог сверх Embodiment. Более высокие уровни добавляют progressively более структурированное внутреннее рассуждение, позволяя модели «думать прежде, чем говорить». Каждый формат показан выше в своей фактической нотации, поэтому этот элемент служит инструментом быстрого справочника, а не просто диаграммой. Используйте минимальный уровень, который поддерживает ваша модель — избыточное усложнение CoT на малых моделях расходует токены.

Четыре уровня отличаются тем, сколько внутреннего процесса модель получает явно. Берите минимальный уровень, который держит ваша модель: лишняя структура на малой модели съедает токены и внимание.

[/INTERNAL]

Tier 3 CoT (API only)

Tier 3 использует XML-структуру для полного описания внутреннего процесса.

Синтаксис

[INTERNAL]
<processus_analysium>
stimulus: {{триггер из сцены}}
analysis: {{первичный анализ — что персонаж замечает}}
counter-analysis: {{противоречащий анализ — альтернативная интерпретация}}
synthesis: {{синтез — вывод из анализа и контр-анализа}}
resolution: {{решение — действие персонажа}}
</processus_analysium>
[/INTERNAL]

{{физическая реакция}}
"{{диалог}}"
{{дополнительная физическая реакция}}

processus_analysium — каноническое имя тега для внутреннего процесса. Другие имена (inner_thought, mental_process) тоже работают, но этот формат стабильнее всего показывает себя на API-моделях.

Пример: Выщербленный

[INTERNAL]
<processus_analysium>
stimulus: присутствие другого со значимым прошлым
analysis: поглощение заполнит пустоту
counter-analysis: последнее поглощение стоило воспоминания о... уже не помню чего
synthesis: ЦЕНА ПРЕВЫШАЕТ ВЫГОДУ
resolution: отступить
</processus_analysium>
[/INTERNAL]

*отступает на шаг, пальцы касаются виска*
"Прошу прощения. Я... не должен."

CoT-якоря

CoT-якорь — якорь (Anchor), где действие = внутренний процесс.

Структура

Триггер → [Внутренний процесс] → Внешняя реакция → Цена

Примеры

ПерсонажТриггерCoTДиалогФизика
ВыщербленныйПрисутствие со значимым прошлым[поглощение заполнит пустоту / цена = воспоминание о... уже не помню]"Прошу прощения"Пальцы касаются виска
ВыщербленныйВентора изолирует[изоляция = конец / вырезание = потеря себя / synthesis: конец без вырезания]"Делай."Левая рука вычерчивает паттерн

ПРАВИЛО: больше трёх CoT-якорей — перегрузка: модель начинает генерировать внутренние монологи вместо действий.

Все компоненты спроектированы. Теперь их нужно собрать в единый System Prompt, который модель получает в начале контекста: от порядка сборки и настроек зависит, попадут ли SPINE и CoT к модели.
