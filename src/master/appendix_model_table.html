Ключевые следствия для сборки карточки

  • 12B-модели: только Tier 0–1 CoT, упрощённая SPINE, ожидать ~60–80% следования основным директивам. Язык SP: для 12B с <64K словарём английский оптимален; для актуальных 12B–14B с ≥128K словарём язык карточки допустим — см. §7A.2 ПРАВИЛО. Налог на письменность (Script Tax) на 32K-словаре увеличивает расход токенов для нелатинских письменностей в 1.5–2 раза.
  • 32B+ модели: полный Tier 0–3 CoT, высокое следование SPINE, ~85–95% следования директивам. Фильтр предгенерации работает надёжно.
  • API-модели: максимальная стабильность, ~90–98% следования. Структурированная инъекция (XML) рекомендуется для сложных персонажей.
