Причинно-следственная цепь

SPINE — психологический стержень персонажа. Каждый элемент причинно-следственно вытекает из предыдущего: GHOST (глубокая травма) порождает LIE (ложное убеждение), которое создаёт FLAW (дезадаптивный паттерн), который двигает NEED (подлинное желание), маскируемое WANT (поверхностная цель). Цепь всегда течёт слева направо. WANT сходится к NEED по мере того, как персонаж платит Prices через Anchors.
