Прогрессия Chain of Thought

CoT не обязателен — Tier 0 работает для всех моделей. На Tier 0 модель не «не думает» — Embodiment Protocol (State → Body → Sensor → Speech) действует всегда как микро-цепочка рассуждений. CoT (Tier 1+) добавляет отдельный [INTERNAL]-блок как явный внутренний монолог сверх Embodiment. Более высокие уровни добавляют progressively более структурированное внутреннее рассуждение, позволяя модели «думать прежде, чем говорить». Каждый формат показан выше в своей фактической нотации, поэтому этот элемент служит инструментом быстрого справочника, а не просто диаграммой. Используйте минимальный уровень, который поддерживает ваша модель — избыточное усложнение CoT на малых моделях расходует токены.
