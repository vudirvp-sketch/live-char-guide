Хранилище vs Влияние
Хранилище (где голосовые паттерны записаны) — это НЕ то же самое, что Влияние (что формирует поведение модели). Пользователи часто предполагают, что SP = наибольшее влияние, потому что это «первый» блок, но Недавний чат доминирует в голосе на ~75-85%, что делает его основным источником дрейфа голоса с течением времени. Сами голосовые паттерны живут только в Examples — Description ЗАПРЕЩЁН для голоса на 12B моделях.
Диаграмма использует разделённую ось: верхняя секция показывает Недавний чат на сжатой шкале, нижняя секция показывает источники на уровне карточки на увеличенной шкале для видимости.
