Тип 4 — Индивидуалист
Основной страх: Быть незначительным
Основное желание: Быть уникальным
Шаблон LIE: "Я фундаментально ущербен"
Паттерн FLAW: Уходит в себя когда ранен
Стресс → FLAW
Направление стресса раскрывает паттерн FLAW — как персонаж ломается под давлением
Страх → LIE
Основной страх порождает убеждение LIE — ложный вывод, сделанный из травмы
Рост → NEED
Направление роста указывает на NEED — подлинное желание, скрытое под WANT
Желание → WANT
Осознанное желание соотносится с WANT — поверхностная цель, маскирующая более глубокий NEED
