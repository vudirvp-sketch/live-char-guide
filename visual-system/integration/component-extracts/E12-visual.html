AP-1
Раздувание токенов
Description превышает бюджет
Исправление:
Сократите до стандартного бюджета. Перенесите детали в Lorebook.
AP-2
Отсутствует Price
У Anchor нет последствия
Исправление:
Добавьте физический, внутри-сценовый Price каждому Anchor.
AP-3
Голос в Description
Голосовые паттерны записаны в блоке Description
Исправление:
Перенесите весь голос в Examples. Description = только факты.
AP-4
GHOST в SP
Элементы SPINE помещены в System Prompt
Исправление:
Перенесите SPINE в Description. SP = только контейнер.
AP-5
RepPen > 1.10
Repetition Penalty установлен слишком высоким
Исправление:
Держите RepPen 1.0–1.05. Используйте MinP вместо этого.
AP-6
Нет Anti-godmoding
Отсутствует 2-строчный anti-godmoding в SP
Исправление:
Добавьте негативную + позитивную строки ограничений в SP.
AP-7
Presence Penalty > 0
PP > 0 нарушает согласованность персонажа
Исправление:
Установите PP = 0.0 всегда. Без исключений.
AP-8
GHOST без Anchors
SPINE определён, но нет Anchors для его выражения
Исправление:
Добавьте FLAW-связанные Anchors в блок Examples.
AP-9
Нарушенный SPINE
Элементы SPINE не образуют причинную цепь
Исправление:
Проверьте причинный поток GHOST→LIE→FLAW→NEED→WANT.
AP-10
Перегрузка CoT
Избыточный CoT на малых моделях
Исправление:
Используйте Tier 0–1 для 12B, Tier 1–2 для 32B.
AP-11
Утечка голоса
Голос персонажа дрейфует к стилю нарратора
Исправление:
Изолируйте голос в Examples. Добавьте усиление в Author's Note.
AP-12
Некорректный XML
Теги неправильно закрыты или вложены
Исправление:
Проверьте все XML-теги. Используйте Format Lock (1 система).
AP-13
Конфликт Lorebook
Запись Lorebook противоречит Description
Исправление:
Аудит Lorebook на согласованность с Description.
AP-14
Нарушение контекста
Общий размер карточки превышает контекстное окно модели
Исправление:
Запустите Budget Check. Сократите или используйте Lorebook для избытка.
AP-15
Вложенные Anchors
Anchors рекурсивно ссылаются друг на друга
Исправление:
Выровняйте структуру Anchors. Только один уровень ссылок.
