Глоссарий

System Prompt (Системный промпт) (SP)
Системные инструкции для модели: ограничения, запреты, формат.
Description (Описание персонажа)
Блок карточки с фактами, SPINE, якорями и OCEAN. Не содержит голосовых директив.
Examples (Примеры диалогов)
Примеры диалогов, задающие голос персонажа через демонстрацию. Единственное место для голосовых паттернов (вместе с Greeting).
Greeting (Первое сообщение)
Первое сообщение персонажа в чате. Задаёт начальное состояние и голос.
Author's Notes (Динамический контекст) (AN)
Динамический слой контекста для длинных сессий. Обновляется каждые 3–5 сообщений.
Character Card (Карточка персонажа)
Полный пакет поведенческого движка персонажа.
Voice Isolation (Изоляция голоса)
Принцип разделения: голос персонажа определяется через Examples, а Description содержит только фактологию и поведенческие инструкции.
SPINE (Мотивационное ядро)
Мотивационное ядро персонажа. На L2: 3 элемента (WANT, NEED, FLAW). На L3: 5 элементов (+ LIE, GHOST).
WANT (Желание)
Осознанное желание персонажа — то, что он думает, что ему нужно.
NEED (Потребность)
Истинная потребность персонажа — то, что ему на самом деле нужно для роста.
FLAW (Дефект)
Изъян персонажа — конкретное поведение, которое мешает ему получить NEED.
LIE (Ложная установка)
Ложная установка — во что персонаж верит, часто мешая себе получить NEED.
GHOST (Призрак)
Событие из прошлого, сформировавшее FLAW и LIE.
Anchors (Поведенческие якоря)
Поведенческие якоря — правила поведения в формате «Триггер → Действие → Цена».
Триггер (Trigger)
Ситуация или стимул, активирующий поведенческий якорь.
Действие (Action)
Наблюдаемое поведение персонажа в ответ на триггер.
Price (Цена)
Немедленная физическая или вербальная манифестация последствия.
Nested Anchors (Вложенные якоря)
Якоря с условным ветвлением: один триггер → несколько действий в зависимости от контекста.
OCEAN (Большая пятёрка)
Модель личности из 5 измерений: Открытость (O), Добросовестность (C), Экстраверсия (E), Доброжелательность (A), Нейротизм (N).
Enneagram (Эннеаграмма)
Система типов личности из 9 типов со стрессом, ростом и крыльями.
MBTI (Типология Майерс-Бриггс)
Типология личности Майерс-Бриггс из 16 типов на основе 4 осей.
CORE DIRECTIVES (Основные директивы) (CD)
Единая система директив на английском языке, размещаемая в System Prompt. L2 = директивы 1–5, L3 = все 7.
Tone Frame (Тональный фрейм) (TF)
Двойной SP-элемент (~25-30 токенов): задаёт тон и фиксирует формат. Пишется на английском в SP.
SHOW NEVER TELL (Показывай, не рассказывай)
Мета-принцип: демонстрируйте через поведение, не описывайте. Основа CORE DIRECTIVES. Пишется на английском.
EMBODIMENT FIRST (Телесность прежде всего)
Директива SP: цепочка Состояние→Тело→Сенсор→Речь. Пишется на английском.
SPATIAL LOCK (Пространственная блокировка)
Директива SP: предотвращает телепортацию и анатомические ошибки. Пишется на английском.
ENVIRONMENTAL REACTIVITY (Реактивность среды)
Директива SP: сенсорные детали только через действие персонажа, не декоративно. Пишется на английском.
INFLUENCE BOUNDARY (Граница влияния)
Директива SP: реагировать только на наблюдаемые симптомы от {{user}}. Не декларировать факты о {{user}}. Пишется на английском.
CONSEQUENCE DRIVEN (Последовательность следствий)
Директива SP #6: WANT сдвигается к NEED по мере накопления Price в сессии. L3-only CORE DIRECTIVE. Пишется на английском.
PRE-GENERATION FILTER (Фильтр предгенерации)
L3-only CORE DIRECTIVE #7. Чеклист перед каждым ответом: embodiment, physical lock, observability, zero-meta. На 12B соблюдается ~40-60%, на API ~85-95%.
SP (MBTI temperament) (SP)
Sensing-Perceiving — темперамент Keirsey (ISTP, ISFP, ESTP, ESFP). Не путать с System Prompt (SP). В гайде обозначается как S·P для различения.
Immersion Boundary (Иммерсионная граница)
Продвинутая OOC-защита: отрицание мета-реальности. L3-only. Персонаж не признаёт существование «игры» или «роли».
Format Lock (Фиксация формата)
Фиксация формата диалога в конце SP. Предотвращает дрейф разметки.
RepPen (Штраф за повторы)
Repetition Penalty — параметр сэмплинга, штрафующий повторение токенов. Рекомендуемый диапазон: 1.00–1.10.
Presence Penalty (Штраф за присутствие) (PP)
Параметр генерации, штрафующий повторение тем. Для карточек персонажей — ОБЯЗАТЕЛЬНО 0.0, иначе голос дрейфует.
CoT (Цепочка рассуждений)
Chain of Thought — цепочка рассуждений. Инструмент для моделей 12B и 32B+.
processus_analysium
L3-only. Каноническое имя XML-тега для внутреннего процесса персонажа. Processus = процесс, analysium = анализ. Протестировано на API моделях (Claude, GPT-4).
Lorebook (База знаний) (LB)
База знаний с триггерами для активации контента по ключевым словам.
Structured Inject (Структурированная инъекция)
Механизм динамического обновления мотивации через AN или LB с XML-тегами.
4K-Fallback (Протокол адаптации)
Протокол адаптации карточки для моделей с ограничением контекста ~4096 токенов.
годмодинг (Godmoding)
Модель пишет за пользователя (действия, мысли, чувства {{user}}).
OOC (Вне образа)
Out of Character — выход из образа.
Voice Contamination (Заражение голоса)
Нарушение голоса персонажа на 12B, вызванное копированием чужих примеров.
Narrator Bleed (Утечка рассказчика)
Смешивание голоса рассказчика с голосом персонажа в Examples. Диагностический термин.
Voice Bleed (Утечка голоса между персонажами)
В мульти-персонажных карточках голос одного персонажа «перетекает» в реплики другого. Диагностический термин.
One Change Rule (Правило одного изменения)
Принцип диагностики: изменение только одного параметра за итерацию для достоверной оценки результата.
Lorebook Entry (Запись Lorebook) (LE)
Отдельная запись в Lorebook с полями Key, Content, Position, Depth, Probability, Cooldown.
