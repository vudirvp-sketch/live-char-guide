## B.1 Таблица возможностей моделей (Model Capability Table)

Эта таблица объединяет всю информацию о зависимости методов от размера модели. Ссылки на эту таблицу заменяют отдельные `MODEL_NOTE`-заметки в тексте гайда.

| Возможность | 12B-модели | 32B+ модели | API-модели |
|---------|------------|-------------|------------|
| Эффективность CoT | Базовая (только Tier 0–1) | Полная (Tier 0–3) | Полная (Tier 0–3) |
| Следование SPINE | Умеренное | Высокое | Высокое |
| Следование CORE DIRECTIVES | ~60–80% | ~85–95% | ~90–98% |
| Управление последствиями (директива №6) | Ограниченный эффект — недостаточная глубина рассуждений | Значительный эффект | Полный эффект |
| Фильтр предгенерации (директива №7) | ~40–60% соблюдения — часто игнорируется | ~85–95% соблюдения | ~90–98% соблюдения |
| Структурированная инъекция (XML) | Ограничена | Хорошая | Хорошая |
| Следование английским инструкциям | Исторически выше на 12B (доминирование английского в обучении); разрыв сужается на словаре ≥128K | Стабильно в обоих языках | Стабильно в обоих языках |
| Размер словаря | 32K (ранние 12B); 128K (актуальные 12B–14B: Gemma 3, Qwen 2.5, Mistral Nemo) | 32K–128K (зависит от поколения) | 100K+ (Claude 200K, GPT-4 128K, Gemini 1M+) |
| Налог на письменность (Script Tax, нелатиница) | Высокий на 32K-словаре (кириллица ≈1.5–2× латиницы; CJK ≈1–2×) | Средний на 32K; низкий на ≥128K | Низкий (словарь 200K+ покрывает большинство письменностей) |

### Ключевые следствия для сборки карточки

- **12B-модели:** только Tier 0–1 CoT, упрощённая SPINE, ожидать ~60–80% следования основным директивам. Язык SP: для 12B с <64K словарём английский оптимален; для актуальных 12B–14B с ≥128K словарём язык карточки допустим — см. §7A.2 ПРАВИЛО. Налог на письменность (Script Tax) на 32K-словаре увеличивает расход токенов для нелатинских письменностей в 1.5–2 раза.
- **32B+ модели:** полный Tier 0–3 CoT, высокое следование SPINE, ~85–95% следования директивам. Фильтр предгенерации работает надёжно.
- **API-модели:** максимальная стабильность, ~90–98% следования. Структурированная инъекция (XML) рекомендуется для сложных персонажей.
