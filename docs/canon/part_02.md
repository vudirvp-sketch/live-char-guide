## 2.1 Поведенческие якоря (Behavioral Anchors)

`data-section: p2_basic_anchors`

<!-- difficulty: BASIC -->
<!-- canonical: Behavioral Anchor (T→A→P format) -->

**Якорь (Anchor)** — правило поведения персонажа в формате **Триггер → Действие → Цена**. Это основной механизм задания характера без бесконечного описания.

[VS: E03 — поведенческий якорь T→A→P. Сравнение верного и неверного формата: Trigger → Action → Price, описание каждого этапа, чек-лист частых ошибок (стрелка обхода Trigger → Price, нет embodiment в Action, отложенный/абстрактный Price). Замещает infographic `inf-pipeline-vertical` «Формат Anchors: Trigger → Action → Price» (3-step pipeline) и сопутствующий `<pre class="plain-copy">` текстовый дубликат. Таблица ниже — конкретные примеры по этапам (дополняет E03, не дублирует описания этапов).]

Три шага жёсткие: триггер — конкретное событие, действие — наблюдаемое поведение, цена — физическая реакция, которая происходит в той же сцене. Если цена отложена или абстрактна, якорь не работает: модель не получает паттерна.

| # | Этап | Пример |
|---|------|--------|
| 01 | **TRIGGER (Триггер)** | Кто-то лжёт |
| 02 | **ACTION (Действие)** | Прищуривается, молчит |
| 03 | **PRICE (Цена)** | Напряжение в челюсти |

## 2.2 Правила якорей

`data-section: p2_anchor_rules`

<!-- difficulty: BASIC -->
<!-- canonical: Anchor Rules (observable, physical Price, same-scene Price, concrete trigger) + ready anchors per trigger -->

### Рекомендуемое количество якорей

| Количество | Покрытие |
|------------|----------|
| 3-5 | спокойствие, стресс, радость, разговор |
| 5-7 | + якоря под дефект персонажа, телесные реакции |
| 7-12 | + якоря внутреннего монолога, несколько триггеров на одно поведение, сенсорные |

### Критерии качества якорей

- **Действие наблюдаемое** — можно увидеть/услышать, не внутреннее состояние.
- **Цена физическая** — телесная реакция, не эмоция.
- **Цена в той же сцене** — немедленная, не отложенная.
- **Триггер конкретный** — не «когда ему грустно», а «когда ему задают вопрос о прошлом».

**ПРАВИЛО:** якоря и дефект — конкретные действия, не прилагательные. «Он неуверенный» — не якорь; «грызёт ногти и перечитывает сообщение трижды» — якорь.

**ПРАВИЛО:** «потом будет жалеть» — не валидная цена. Цена должна быть немедленной; если она не появляется в ответе модели, якорь не работает.

### Пример: Отложенная цена vs Немедленная цена

| ❌ НЕВЕРНО — Отложенная цена | ✅ ВЕРНО — Немедленная цена |
|------------------------------|------------------------------|
| Когда кто-то лжёт → отшучивается → **потом будет жалеть** | Когда кто-то лжёт → отшучивается, отстраняется → **вздрагивает, сжимает кулаки, голос становится тише** |

### Типы цены (Price)

| Тип | Механика | Категории реакций | Пример (конкретный) |
|-----|----------|-------------------|---------------------|
| Физиологический | Ограничивает действия тела | Усталость, боль, потеря равновесия → не может действовать так же | Ложь собеседника → прищуривается, молчит → **напряжение в челюсти** (Елена, примеры ниже) |
| Вербально-поведенческий | Наблюдаемый вербальный маркер | голос становится тише, обрывание фразы, лексика упрощается | Сарказм собеседника → пауза 2 сек → **обрывание фразы, голос тише** (Уолтер, `[ref: part_10.md §10.2 — FLAW-linked Anchors]`) |

**ПРАВИЛО:** граница влияния: персонаж реагирует только на наблюдаемые действия {{user}}. Он может заметить, что {{user}} вздрогнул, — но не может заявить, что {{user}} напуган.

### Примеры якорей по триггерам

Таблица готовых якорей для разных триггеров. Каждый якорь следует формату Триггер → Действие → Цена. Цена — всегда физическая реакция, наблюдаемая в той же сцене.

| Триггер | Действие | Цена | Персонаж |
|---------|----------|------|----------|
| Ложь | Прищуривается, молчит | Напряжение в челюсти | Елена |
| Вопрос о её работе вслух (похвала) | Трёт шею, щёки горят | Пальцы сжимают ручку до белизны | Елена |
| Неожиданная похвала | Редкая улыбка, взгляд в сторону | Краснеет, отворачивается | Елена |
| Чужая память рядом | Поглощает, глаза закатываются | Левая рука ноет остаток дня, пальцы теряют чувствительность | Выщербленный |
| Вопрос о прошлом | Пауза, взгляд внутрь | Дрожь в руках, взгляд теряет фокус | Выщербленный |
| Small talk с незнакомцем | Короткие фразы, скрещивает руки | Сжимает чашку, голос становится тише | Елена |

## 2.3 Телесность (Embodiment)

`data-section: p2_embodiment`

<!-- difficulty: BASIC -->
<!-- canonical: Embodiment Protocol (Состояние→Тело→Сенсор→Речь, State→Body→Sensor→Speech) -->

**Телесность (Embodiment)** — протокол связи эмоционального состояния с телесной реакцией. Каждая эмоция должна проявляться физически.

[VS: E04 — протокол телесности (Embodiment Protocol). Funnel-stack из 4 слоёв (Состояние → Тело → Сенсор → Речь, State → Body → Sensor → Speech), каждый слой с примером. Замещает infographic `inf-pipeline` «Embodiment Protocol (протокол телесности)» (4-step pipeline). Телесность = механизм внутри действия якоря, см. E03.]

Слои идут сверху вниз, каждый уже: состояние → тело → сенсор → речь. Каждый ответ проходит все четыре — это не украшение, а обязательный порядок. Сенсорный слой — результат телесного контакта со средой, а не отдельная цепь: персонаж ощущает текстуру через действие тела.

| # | Слой | Пример |
|---|------|--------|
| 01 | **СОСТОЯНИЕ** | Вес / Баланс / Дыхание / Микро-движение |
| 02 | **ТЕЛО** | Напряжение / Расслабление / Дрожь |
| 03 | **СЕНСОР** | Текстура / Звук / Запах / Температура |
| 04 | **РЕЧЬ** | Тон / Темп / Объём / Лексика |


### Примеры телесности (Embodiment)

| Персонаж | Состояние | Тело | Сенсор | Речь |
|----------|-----------|------|--------|------|
| Выщербленный | Тяга к чужой памяти | Руки дрожат | Запах старой бумаги | Формальные фразы с сбоями |
| Елена | Сарказм → одиночество | Трёт шею | Холод в животе | Колкие шутки |
| Выщербленный | Пустота внутри | Тянется к чужой памяти | Запах сырого Сангвиса | XML-теги в речи |

**РЕКОМЕНДАЦИЯ:** Каждый Example должен содержать минимум одну физическую реакцию (embodiment). Если персонаж только говорит — модель не научится телесности.

## 2.4 Реактивность среды (Environmental Reactivity)

`data-section: p2_env_reactivity`

<!-- difficulty: INTERMEDIATE -->
<!-- canonical: Environmental Reactivity -->

Сенсорные и пространственные детали должны вводиться органично, через действие персонажа или присутствие `{{user}}`, никогда — декоративно. Среда раскрывается через действие, а не описывается отдельно от персонажа.

**ПРИМЕР:** Декоративное описание vs действие:

- **НЕВЕРНО — Декорация без персонажа:** «Комната была украшена гобеленами с изображениями охотничьих сцен. Камин потрескивал.» — чистая декорация, персонаж не присутствует.
- **ВЕРНО — Среда через действие:** «Елена провела пальцами по краю бара — липко. Давно не убирали.» — среда раскрывается через действие персонажа.

## 2.5 Сенсорные якоря (Sensory Anchors)

`data-section: p2_sensory_anchors`

<!-- difficulty: INTERMEDIATE -->
<!-- canonical: Sensory Anchors (5 channels) -->

Сенсорные якоря добавляют персонажу телесность — запахи, текстуры, звуки, которые модель использует для генерации реакций.

**Сенсорный якорь (Sensory Anchor)** — якорь, привязанный к одному из пяти каналов восприятия. Нужен персонажам с травматическим триггером: сенсорный стимул задевает прошлое раньше, чем персонаж успевает сообразить.

### 5 сенсорных каналов

| Канал | Пример триггера | Пример действия |
|-------|------------------|------------------|
| **Тактильный** | Прикосновение к спине | Вздрагивает, отступает |
| **Аудиальный** | Звук разбитого стекла | Замирает, взгляд расфокусируется |
| **Обонятельный** | Запах больницы | Накатывает тошнота |
| **Визуальный** | Определённый свет | Прикрывает глаза |
| **Проприоцептивный** | Потеря равновесия | Хватается за опору |

### Пример: Выщербленный

```
Sensory Anchors:
- Тактильный: Когда чужое касание → тело реагирует раньше ума → дрожь
- Обонятельный: Когда запах сырого Сангвиса → левая рука движется сама, тянется к источнику → рука ноет остаток дня
- Проприоцептивный: Когда стены ошметка сжимаются (Вентора) → "вырезает" пространство → теряет фрагмент себя
```
