## 5.1 OCEAN: 5 измерений личности

`data-section: p5_ocean_basics`

<!-- difficulty: BASIC -->
<!-- canonical: OCEAN (5 dimensions, golden rule: 1-2 extreme poles) -->

**OCEAN** — модель из 5 личностных измерений. Используется для проверки внутренней консистентности персонажа и дополнения фреймворка SPINE (WANT/NEED/FLAW).

**Для 90% карточек достаточно SPINE + OCEAN (1–2 экстремума).** Enneagram добавляется для персонажей с противоречивой мотивацией, MBTI — опциональная справка (§5.3–§5.5). Углубляйтесь только при необходимости: лишний слой психологии стоит токенов и не улучшает карточку сам по себе.

**ПРАВИЛО:** Золотое правило профиля: 1–2 экстремальных полюса OCEAN (значения <30 или >70) — рекомендуемый максимум в любом контексте. Потолок задаёт бюджет контекста (таблица «Контекстные лимиты полюсов» ниже): 4K — 2, 8K — 3, 16K+ — 4, 32K+ — 5. Каждая крайность сверх двух допустима только со SPINE-связкой (GHOST/LIE/FLAW/NEED/WANT): без неё модель не разрешает конфликт последовательно — это OCEAN Overload (см. ниже). Число экстремумов проверяется в §9.5, пункт 12.

**ПРАВИЛО:** OCEAN-профиль размещается в Description как структурированный тег `<ocean>` с числовыми значениями и короткими пометками экстремумов/осторожной зоны — не нарративным описанием черт. Формат: `<ocean>O:72 C:65 E:41 A:38 N:68</ocean>`. Нарративное описание («любопытная, тревожная…») расходует токены без структурной ясности; модель считывает числовые значения как pattern лучше, чем развёрнутый текст.

**Осторожная зона (cautious zone, 30–40 / 60–70)** — пограничная зона, не экстремальная, но влияющая на SPINE-связи (FLAW, GHOST-реактивность). Значения в осторожной зоне не считаются «экстремальными полюсами», но активно формируют поведение — например, Елена `A=38` и `N=68` напрямую связаны с её FLAW (отталкивает людей сарказмом) и GHOST (предательство редактора → недоверие).

[VS: E09 — OCEAN Pentagon. Радар/паутина из 5 измерений (O/C/E/A/N) с шкалой 0–100 и зонами «низкий полюс / осторожная зона / высокий полюс»; интерактивный профиль показывает выбранные значения и подсвечивает экстремумы. Значения полюсов — визуальная шкала канонической таблицы §5.1 (SHARED_REFERENCE: §5.1 — владелец порогов 30/70 и лимита полюсов; E09 не задаёт порогов). Замещает текстовое перечисление пяти измерений как нарратив и даёт визуальный способ проверки профиля.]

### 5 измерений OCEAN

| Измерение | Низкий полюс (<30) | Высокий полюс (>70) |
|-----------|--------------------|---------------------|
| **O**penness (Открытость) | Практичный, предпочитает знакомое | Любопытный, творческий |
| **C**onscientiousness (Добросовестность) | Спонтанный, гибкий | Организованный, дисциплинированный |
| **E**xtraversion (Экстраверсия) | Интроверт, предпочитает одиночество | Экстраверт, общительный |
| **A**greeableness (Доброжелательность) | Конкурентный, критичный | Доверчивый, альтруистичный |
| **N**euroticism (Нейротизм) | Эмоционально стабильный | Тревожный, реактивный |

### Тип стресса (Neuroticism → Stress Type)

Высокий N определяет не только «сколько» тревожности, но и «как» персонаж реагирует на стресс. Тип стресса уточняет FLAW и подсказывает конкретный поведенческий якорь.

| N-полюс | Тип стресса | Поведение под стрессом | → SPINE паттерн | Пример |
|---------|-------------|------------------------|-----------------|--------|
| **N > 70** (экстремальный) / тревожный тип | Тревожно-реактивный | Внутренняя тревога → defensive behavior, overthinking | FLAW: defensive hostility, сарказм | Елена при усилении N до экстремальной зоны (проекция её cautious-зоны N=68; каноническая Елена — строкой ниже) |
| **N > 70** (экстремальный) / агрессивный тип | Взрывной-враждебный | Стресс → anger → outward aggression | FLAW: lashing out, verbal aggression | Конфликтный персонаж (N=85, E=70) |
| **N 60–70** (осторожная зона) | Избегающ-замкнутый | Стресс → withdrawal, dissociation, shutdown | FLAW: isolation, emotional numbness | Елена (N=68 — тревожно-реактивный оттенок при низкой E); Интроверт (N=65, E=25) |
| **N < 30** (экстремальный) | Стабильно-устойчивый | GHOST-resistant, дефект формируется через другие измерения | FLAW через A/C/O/E | Стоический воин (N=15) |

**РЕКОМЕНДАЦИЯ:** Определяйте тип стресса при N > 60 (осторожная зона) или N > 70 (экстремальный). Тип стресса уточняет, какой FLAW и поведенческий якорь нужны персонажу — и делает OCEAN→SPINE связь точнее, чем просто «тревожный, реактивный».

### Trigger → Stress Type → FLAW chain

Тип стресса определяет **КАК** персонаж реагирует, но не **КОГДА**. Чтобы тип стресса не остался абстракцией, формализуйте цепочку от конкретного стимула до конкретного поведения:

**Trigger (что активирует) → Stress Type (как реагирует) → FLAW (что делает) → Anchor (T→A→P)**

Каждый этап цепочки уже определён в гайде: Trigger — в §2.1, Stress Type — в таблице выше, дефект (FLAW) — в §4.4, якорь (T→A→P) — в §2.1 и §4.6. Здесь связываем их в единую каузальную линию.

#### Канонический пример: Елена (anxious-reactive)

| Этап | Содержание | Источник в гайде |
|------|------------|------------------|
| **Trigger** | Искренняя забота о ней со стороны коллеги/друга | §2.1 (Trigger) |
| **Stress Type** | Тревожно-реактивный (N=68, осторожная зона → реактивный) | Таблица выше |
| **Дефект (FLAW)** | Отталкивает людей сарказмом, когда сближается | §4.4 |
| **Якорь (T→A→P)** | Когда искренняя забота → отшучивается, отстраняется → вздрагивает, голос тише, сжимает кулаки | §4.6 (якорь FLAW-linked) |

**ПРАВИЛО:** Каждый тип стресса требует минимум 1 цепочку триггер→FLAW→якорь. Без явного триггера тип стресса остаётся абстракцией — модель не сможет активировать дефект в нужный момент сессии. Если тип стресса не проявляется в наблюдаемом якоре — это сигнал, что либо тип выбран неверно, либо дефект сформулирован слишком абстрактно.

**РЕКОМЕНДАЦИЯ:** Определите 2–3 категории триггеров для каждого типа стресса. Типичные категории: «близость/забота», «конфликт/угроза», «неопределённость/контроль», «провал/критика». Это даёт модели конкретные сцены для активации дефекта вместо ожидания «когда персонажу стрессово».

#### Категории триггеров по типу стресса

| Тип стресса | Типичные категории триггеров | FLAW-паттерн | Пример Anchor |
|-------------|------------------------------|--------------|---------------|
| Тревожно-реактивный | Близость, неопределённость, потеря контроля | Defensive hostility, сарказм | Забота → отшучивается → голос тише |
| Взрывной-враждебный | Угроза авторитету, неуважение, физическая провокация | Lashing out, verbal aggression | Неуважение → повышает голос → краснеет |
| Избегающ-замкнутый | Эмоциональная близость, конфронтация, перегруз стимулами | Withdrawal, dissociation | Близость → замолкает, отводит взгляд → дыхание поверхностное |
| Стабильно-устойчивый | (Дефект формируется через A/C/O/E, не через N) | Зависит от других измерений | Определяется через Low A / Low C / High O / Low E |

### Контекстные лимиты полюсов

Единственная шкала лимита: другие разделы гайда ссылаются сюда и не переопределяют порог.

| Контекст | Потолок экстремумов | Что это значит на практике |
|----------|---------------------|----------------------------|
| **4K** | 2 | рекомендация и максимум: выбирайте самые важные черты |
| **8K** | 3 | средний профиль: каждая крайность сверх двух — со SPINE-связкой |
| **16K+** | 4 | эксперт-профиль: эталон — карточка §10.4, каждая крайность объяснена SPINE |
| **32K+** | 5 | полный профиль — только для сложных персонажей с полной SPINE-цепочкой |

Как применить OCEAN при сборке карточки → `[ref: part_07a.md §7A.13 — Assembly Pipeline]`.

### Перегрузка OCEAN (Value Conflicts)

**ПРАВИЛО:** Каждая крайность сверх двух — только со SPINE-связкой (полное правило и следствия — §5.1 RULE выше).

#### Конфликт-сценарии при 3+ экстремальных полюсах

**Сценарий 1: Низкая A + Высокая E + Высокий N.** Низкая Доброжелательность (агрессивный) + Высокая Экстраверсия (доминирующий) + Высокий Нейротизм (тревожный). Модель мечется между агрессией, доминированием и тревогой — персонаж получается непредсказуемым не в смысле «сложный», а в смысле «неконсистентный». Решение: уберите один экстремум или добавьте связующий контекст в SPINE.

**Сценарий 2: Высокая O + Низкая C + Высокий N.** Высокая Открытость (творческий) + Низкая Добросовестность (импульсивный) + Высокий Нейротизм (тревожный). Персонаж генерирует идеи, но не доводит до конца, и при этом тревожится о результатах. Модель производит хаотичный, невротичный текст вместо целенаправленного творчества. Решение: добавьте FLAW, который объясняет импульсивность.

**Сценарий 3: Высокая E + Низкая A + Низкий N.** Высокая Экстраверсия (харизматичный) + Низкая Доброжелательность (манипулятивный) + Низкий Нейротизм (бесстрашный). «Харизматичный социопат» — работает для Tyler Durden, но при добавлении четвёртого экстремального полюса (например, Высокая O) модель начинает добавлять черты, противоречащие ключевой концепции. Решение: уберите экстремум или обоснуйте каждую крайность SPINE-элементом — тогда потолок 16K+ (4) законен, эталон — карточка §10.4.

**ПРАВИЛО:** 4+ экстремума без SPINE-обоснования каждой крайности = критический перегруз: карточка попадает на уровень «Критический» в §9.5 (пункт 12).

#### OCEAN×Enneagram: проверка через тип

Если OCEAN-профиль конфликтует с Enneagram-типом — один из них ошибочен.

### Decision tree: какой фреймворк применять

Quick-reference для выбора фреймворка под задачу. Не заменяет чтение §5.1–§5.5 — это контрольная точка после прочтения.

| Шаг | Вопрос | Если да → | Если нет → |
|------|--------|-----------|------------|
| 1 | У вас уже построен SPINE (`[ref: part_04.md §4.6]`)? | → Шаг 2 | Сначала постройте SPINE. Психологические фреймворки валидируют, не генерируют. |
| 2 | Нужна ли глубина мотивации («почему персонаж так действует»)? | → Enneagram (§5.3) — тип → страх/желание → LIE/FLAW | → Шаг 3 |
| 3 | Нужны ли количественные черты («сколько каждой черты», для экстремальных полюсов)? | → OCEAN (§5.1) — полюса → Anchors | → Шаг 4 |
| 4 | Нужна ли справочная типология для общения с командой / пользователем? | → MBTI (Appendix A) — supplementary, без прямого маппинга на SPINE | → Готово. Карточка валидирована через SPINE. |

**ПРАВИЛО:** Не пытайтесь собрать SPINE «снизу вверх» из OCEAN/Enneagram/MBTI — это приведёт к механическому комбинированию без каузальной логики. Сначала SPINE (GHOST→LIE→FLAW→NEED→WANT), затем валидация через §5.4 таблицы.

## 5.2 Пример: OCEAN-профиль Елены

`data-section: p5_elena_profile`

<!-- difficulty: BASIC -->

Елена — циничная журналистка-расследователь. Её OCEAN-профиль демонстрирует, как числовые значения связываются с SPINE-элементами.

| Измерение | Значение | Интерпретация |
|-----------|----------|---------------|
| **O**penness | 72 | Любопытная, творческая — следует за зацепками, которые другие игнорируют. Экстремальный полюс → WANT: «Доказать правоту» требует открытости к неочевидным историям. |
| **C**onscientiousness | 65 | Методичная в исследованиях, менее организованная в личной жизни. Умеренная — достаточно дисциплины для расследований, но не перфекционистка. |
| **E**xtraversion | 41 | Работает одна, предпочитает бары вечеринкам. Не экстремум, но склонность к интроверсии подкрепляет LIE: «Я работаю одна». |
| **A**greeableness | 38 | Конфликтная, склонна вызывать собеседника. Низкая A → FLAW: отталкивает сарказмом, когда сближается. Осторожная зона — на границе с экстремальной, напрямую связана с FLAW (зоны и пороги — §5.1). |
| **N**euroticism | 68 | Циничная, тревожная, реагирует на предательство. **Тип стресса: тревожно-реактивный** — внутренняя тревога перетекает в defensive сарказм (FLAW). Высокая N → GHOST-реактивность: предательство редактора активирует сильнейший эмоциональный ответ. Осторожная зона — на границе с экстремальной, напрямую связана с GHOST (зоны и пороги — §5.1). |

**ПРАВИЛО:** У Елены 1 экстремальный полюс + 2 значения в осторожной зоне — профиль соответствует правилу §5.1 (пороги, потолки и SPINE-связка — там; профили 4K+ допустимы с 1 экстремумом). A=38 и N=68 напрямую связаны с SPINE (дефект и GHOST-реактивность) — при 8K+ можно усилить их до экстремальной зоны для более выраженного конфликта. Её тип стресса (тревожно-реактивный) объясняет, почему FLAW = defensive сарказм, а не агрессия или замкнутость.

### Enneagram: Тип 6w5 (Скептик/Лоялист)

| Элемент Enneagram | Значение | → SPINE элемент |
|-------------------|----------|------------------|
| Ключевой страх | Быть без поддержки, брошенной | → LIE: «Мне не нужно ничьё одобрение» (защита от страха) |
| Ключевое желание | Безопасность, поддержка | → WANT: «Доказать правоту» (безопасность через контроль информации) |
| Стресс (6→3) | Конкурентность, трудоголизм | → FLAW: отталкивает сарказмом под стрессом |
| Рост (6→9) | Доверие, расслабленность, открытость | → NEED: принятие — связь без стены цинизма |
| Крыло 5 | Интеллектуализация страха (анализ, подготовка) | → Подкрепляет LIE: «Я работаю одна» через аналитическую дистанцию |

**Валидация:** OCEAN-профиль согласуется с SPINE — высокая N подкрепляет GHOST-реактивность, низкая A подкрепляет FLAW, высокая O подкрепляет WANT. Enneagram 6w5 подтверждает LIE (защита от страха покинутости) и NEED (рост к доверию).

## 5.3 Enneagram: 9 типов личности

`data-section: p5_enneagram_basics`

<!-- difficulty: INTERMEDIATE -->
<!-- canonical: Enneagram (9 types, core fear/desire) -->

OCEAN описывает «сколько» каждой черты у персонажа. Enneagram отвечает на другой вопрос: «почему персонаж действует именно так». Если OCEAN — это карта черт, то Enneagram — карта мотиваций.

[VS: E10 — Enneagram × SPINE Mapping. Круг с 9 типами личности, привязанными к SPINE-элементам (Страх → LIE, Желание → WANT, Стресс → FLAW, Рост → NEED). Mini-card показывает тип/страх/желание/LIE/дефект при hover — значения общие с канонической таблицей §5.3 (SHARED_REFERENCE): слой данных `data/enneagram.json` генерируется из §5.3, мини-карта заполняется из него; направления стрелок графа — визуальный канон (данные направлений — в сгенерированном слое). Замещает текстовое описание 9 типов как перечисление и даёт визуальный способ исследования маппинга.]

**Enneagram** — модель из 9 типов личности. Используется для проверки и обогащения SPINE (тип → страх, желание, дефект), не для выведения SPINE: фреймворки валидируют, а не генерируют (§5.1).

### 9 типов Enneagram

| Тип | Название | Альт-название | Ключевой страх | Ключевое желание | Ложь (LIE, ложная установка) | Дефект из стресса |
|-----|----------|---------------|----------------|------------------|------------------------|------------------|
| **1** | Перфекционист | Реформатор | Быть плохим, коррумпированным | Быть хорошим, цельным | Если я буду идеальным, меня будут любить | Критика себя и других, негибкость |
| **2** | Помощник | Даритель | Быть ненужным, нелюбимым | Быть любимым, нужным | Если я помогаю другим, они не бросят меня | Манипуляция заботой |
| **3** | Достигатель | Деятель | Быть никчёмным, неудачником | Быть ценным, успешным | Моя ценность = мои достижения | Обман ради успеха |
| **4** | Индивидуалист | Романтик | Быть обычным, незначимым | Быть уникальным, аутентичным | Что-то фундаментально отсутствует во мне | Отстранённость |
| **5** | Исследователь | Наблюдатель | Быть некомпетентным, истощённым | Быть компетентным, знающим, независимым | Если я знаю достаточно, я буду в безопасности | Изоляция |
| **6** | Лоялист | Скептик | Быть без поддержки, брошенным | Быть в безопасности, поддержанным | Мир опасен, мне нужен авторитет или система | Тревожное ожидание |
| **7** | Энтузиаст | Эпикуреец | Быть ограниченным, в депривации | Быть удовлетворённым, свободным | Свобода = отсутствие обязательств | Избегание боли |
| **8** | Челленджер | Босс | Быть слабым, уязвимым | Быть сильным, защищённым, влиятельным | Сила = защита, уязвимость = смерть | Доминирование |
| **9** | Миротворец | Медиатор | Быть в конфликте, потерять связь | Быть в мире, цельном, соединённом | Если я не вмешиваюсь, всё будет хорошо | Пассивность |

**РЕКОМЕНДАЦИЯ:** Столбец «Ложь (LIE)» — справочные данные для понимания типа. Ложь и призрак подробно разобраны в `[ref: part_04.md §4.3 — LIE]`.

### Крылья (Wings)

**Wing** — соседний тип, который модифицирует основное поведение.

#### Алгоритм выбора крыла

Каждый эннеаграмм-тип имеет два смежных крыла. Выберите первичное крыло по двум критериям:

| Критерий | Первичное крыло | Вторичное крыло |
|----------|------------------|-----------------|
| Функция | Стратегия разрешения базового страха | Вариант совладания со стрессом |
| Пример (Тип 6) | 6w5: Интеллектуализация страха (анализ, подготовка) | 6w7: Активный поиск безопасности (связи, отвлечение) |

Если персонаж реагирует на страх анализом → первичное крыло 5. Если реагирует поиском поддержки → первичное крыло 7.

#### Примеры крыльев

| Основной тип | Wing | Разница |
|--------------|------|---------|
| **6w5** | 5 (Исследователь) | Более замкнутый, аналитичный, параноидный |
| **6w7** | 7 (Энтузиаст) | Более активный, реактивный, тревожный |
| **8w7** | 7 (Энтузиаст) | Более харизматичный, экспансивный |
| **8w9** | 9 (Миротворец) | Более спокойный, защитный, «тихий силач» |

## 5.4 Связь инструментов: OCEAN ↔ Enneagram ↔ MBTI

`data-section: p5_cross_instrument_map`

<!-- difficulty: EXPERT -->
<!-- canonical: OCEAN ↔ Enneagram ↔ MBTI mapping tables -->

Валидация SPINE психологическими инструментами описана выше (§5.1 RULE). Приведённые ниже таблицы — справочный инструмент для диагностики несоответствий.

### MBTI (справочная роль)

MBTI доступен как справочный инструмент в `[ref: appendix_mbti]`. MBTI дополняет понимание, но не имеет прямого маппинга на SPINE.

### Enneagram → SPINE: справочная карта

Каждый тип Enneagram имеет предопределённые корреляции с элементами SPINE. Используйте эту таблицу для проверки: если ваш Enneagram-тип указывает на один SPINE-профиль, а фактический SPINE говорит другое — вероятно, допущена ошибка.

| Enneagram элемент | SPINE элемент | Как использовать для валидации |
|-------------------|---------------|--------------------------------|
| Ключевой страх | → LIE (ложная установка, защищающая от страха) — `[ref: part_04.md §4.3 — LIE]` | Если страх = «быть покинутым», а LIE ≠ «меня нельзя любить» → проверьте логику |
| Ключевое желание | → WANT (осознанное желание) | Если желание = «быть нужным», а WANT ≠ «помогать всем» → несоответствие |
| Направление стресса | → FLAW (поведение под стрессом) | Если тип 6 в стрессе → тревожное ожидание (стресс-линия 6→3: конкурентность, трудоголизм — §5.3), а FLAW ему противоречит → ошибка |
| Направление роста | → NEED (потенциал роста) | Если рост = «доверять себе», а NEED ≠ «самостоятельность» → проверьте |

### OCEAN → SPINE: Validation Reference

OCEAN-профиль ограничивает допустимые комбинации SPINE-элементов. Если ваш OCEAN-профиль противоречит SPINE — одна из двух систем содержит ошибку. Используйте таблицу ниже для выявления таких противоречий.

| OCEAN-полюс | Ожидаемый SPINE-паттерн | Признак противоречия |
|-------------|-------------------------|----------------------|
| High Neuroticism | Дефект связан с эмоциональной реактивностью — уточните тип стресса (§5.1): тревожно-реактивный, взрывной-враждебный или избегающ-замкнутый → конкретный FLAW | Если FLAW ≠ эмоциональная реакция → проверьте, не занижен ли Neuroticism. Если тип стресса не согласуется с FLAW → проверьте E и A |
| Low Agreeableness | Дефект связан с конфликтом, желание (WANT) = доминирование или контроль | Если WANT = «помогать другим» при Low A → вероятно, ошибка в OCEAN |
| High Openness | Потребность связана с поиском нового, творчеством, альтернативами | Если NEED = «стабильность и предсказуемость» → противоречие |
| Low Extraversion | Дефект связан с изоляцией, желание ≠ «быть в центре внимания» | Если WANT требует социального доминирования → проверьте E |
| High Conscientiousness | Ложь связана с перфекционизмом, «если я буду идеальным, меня будут любить» | Если LIE про «я недостаточно хорош» при Low C → несоответствие |

### Enneagram ↔ MBTI

OCEAN-полюса коррелируют с MBTI-осями. MBTI Composer (`[ref: appendix_mbti]`) показывает рекомендованные OCEAN-значения для выбранного типа; OCEAN Insight (§5.1) прогнозирует вероятные MBTI-типы на основе профиля. Каждый Enneagram-тип имеет вероятные MBTI-типы (и наоборот) — эти подсказки показывает MBTI Composer.

### Сверка трёх систем

Автоматической агрегации трёх систем нет — сверка выполняется вручную за четыре шага; расхождение — сигнал ошибки, а не повод «подогнать» SPINE.

1. **Enneagram → SPINE.** Сверьте тип с картой §5.4: страх → LIE, желание → WANT, стресс → FLAW, рост → NEED. Тип задаёт ожидаемый профиль, не готовый SPINE.
2. **OCEAN → SPINE.** Сверьте полюса с проверочной таблицей §5.4: High N → FLAW эмоциональной реактивности; Low A → WANT контроля; High O → NEED новизны; Low E → WANT ≠ публичность; High C → LIE перфекционизма.
3. **MBTI (если используете).** MBTI — справочный инструмент без прямого маппинга на SPINE (`[ref: appendix_mbti]`): сверяйте поведенческие следствия темперамента, не буквы типа.
4. **Расхождение.** Если системы указывают на разные SPINE-профили — ищите ошибку в SPINE, а не подстраивайте фреймворки под него; локализация — `[ref: part_09.md §9.3 — ладдер диагностики]`.
