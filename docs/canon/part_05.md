## 5.1 OCEAN: 5 измерений личности

`data-section: p5_ocean_basics`

**OCEAN** — модель из 5 личностных измерений. Используется для проверки внутренней консистентности персонажа и дополнения фреймворка SPINE (WANT/NEED/FLAW).

**RULE:** Золотое правило профиля: Только 1–2 экстремальных полюса OCEAN (значения <30 или >70). Каждый дополнительный экстремальный полюс снижает стабильность поведения. Нарушение = OCEAN Value Conflicts (см. §5.3).

### 5 измерений OCEAN

| Измерение | Низкий полюс (<30) | Высокий полюс (>70) |
|-----------|--------------------|---------------------|
| **O**penness (Открытость) | Практичный, предпочитает знакомое | Любопытный, творческий |
| **C**onscientiousness (Добросовестность) | Спонтанный, гибкий | Организованный, дисциплинированный |
| **E**xtraversion (Экстраверсия) | Интроверт, предпочитает одиночество | Экстраверт, общительный |
| **A**greeableness (Доброжелательность) | Конкурентный, критичный | Доверчивый, альтруистичный |
| **N**euroticism (Нейротизм) | Эмоционально стабильный | Тревожный, реактивный |

### Контекстные лимиты полюсов

| Контекст | Экстремальных полюсов | Рекомендация |
|----------|------------------------|--------------|
| **4K** | 1–2 | Минимум — выбрать самые важные |
| **8K** | 2–3 | Средний профиль |
| **16K+** | 3–4 | Богатый профиль |
| **32K+** | Полный (5) | Только для сложных персонажей |

**Cross-ref:** Как применить OCEAN при сборке карточки → `[ref: part_07a.md §7A.X — Assembly Pipeline]`.

## 5.2 Пример: OCEAN-профиль Елены

`data-section: p5_elena_profile`

Елена — циничная журналистка-расследователь. Её OCEAN-профиль демонстрирует, как числовые значения связываются с SPINE-элементами.

| Измерение | Значение | Интерпретация |
|-----------|----------|---------------|
| **O**penness | 72 | Любопытная, творческая — следует за зацепками, которые другие игнорируют. Экстремальный полюс → WANT: «Доказать правоту» требует открытости к неочевидным историям. |
| **C**onscientiousness | 65 | Методичная в исследованиях, менее организованная в личной жизни. Умеренная — достаточно дисциплины для расследований, но не перфекционистка. |
| **E**xtraversion | 41 | Работает одна, предпочитает бары вечеринкам. Не экстремум, но склонность к интроверсии подкрепляет LIE: «Я работаю одна». |
| **A**greeableness | 38 | Конфликтная, склонна вызывать собеседника. Низкая A → FLAW: отталкивает сарказмом, когда сближается. Экстремальный полюс. |
| **N**euroticism | 68 | Циничная, тревожная, реагирует на предательство. Высокая N → GHOST-реактивность: предательство редактора активирует сильнейший эмоциональный ответ. Экстремальный полюс. |

**RULE:** У Елены 3 экстремальных полюса (O=72, A=38, N=68). Это допустимо для 8K+ контекста, но для 4K следует оставить только 2 (рекомендация: N=68 и A=38 — они напрямую связаны с SPINE).

### Enneagram: Тип 6w5 (Скептик/Лоялист)

| Элемент Enneagram | Значение | → SPINE элемент |
|-------------------|----------|------------------|
| Ключевой страх | Быть без поддержки, брошенной | → LIE: «Мне не нужно ничьё одобрение» (защита от страха) |
| Ключевое желание | Безопасность, поддержка | → WANT: «Доказать правоту» (безопасность через контроль информации) |
| Стресс (6→3) | Конкурентность, трудоголизм | → FLAW: отталкивает сарказмом под стрессом |
| Рост (6→9) | Доверие, расслабленность, открытость | → NEED: принятие — связь без стены цинизма |
| Крыло 5 | Интеллектуализация страха (анализ, подготовка) | → Подкрепляет LIE: «Я работаю одна» через аналитическую дистанцию |

**Валидация:** OCEAN-профиль согласуется с SPINE — высокая N подкрепляет GHOST-реактивность, низкая A подкрепляет FLAW, высокая O подкрепляет WANT. Enneagram 6w5 подтверждает LIE (защита от страха покинутости) и NEED (рост к доверию).

## 5.3 OCEAN Value Conflicts (перегрузка)

`data-section: p5_ocean_warning`

**RULE:** OCEAN Overload: Более 2 экстремальных полюсов OCEAN создают внутренние конфликты, которые модель не может разрешить последовательно.

### Конфликт-сценарии при 3+ экстремальных полюсах

#### Сценарий 1: Низкая A + Высокая E + Высокий N

**Расшифровка:** Низкая Доброжелательность (агрессивный) + Высокая Экстраверсия (доминирующий) + Высокий Нейротизм (тревожный).

Модель мечется между агрессией, доминированием и тревогой — персонаж получается непредсказуемым не в смысле «сложный», а в смысле «неконсистентный». Решение: уберите один экстремум или добавьте связующий контекст в SPINE.

#### Сценарий 2: Высокая O + Низкая C + Высокий N

**Расшифровка:** Высокая Открытость (творческий) + Низкая Добросовестность (импульсивный) + Высокий Нейротизм (тревожный).

Персонаж генерирует идеи, но не доводит до конца, и при этом тревожится о результатах. Модель производит хаотичный, невротичный текст вместо целенаправленного творчества. Решение: добавьте FLAW, который объясняет импульсивность.

#### Сценарий 3: Высокая E + Низкая A + Низкий N

**Расшифровка:** Высокая Экстраверсия (харизматичный) + Низкая Доброжелательность (манипулятивный) + Низкий Нейротизм (бесстрашный).

«Харизматичный социопат» — работает для Tyler Durden, но при добавлении четвёртого экстремального полюса (например, Высокая O) модель начинает добавлять черты, противоречащие ключевой концепции. Решение: максимум 3 экстремума для 8K+, 2 для 4K.

### OCEAN×Enneagram: проверка через тип

Если OCEAN-профиль конфликтует с Enneagram-типом — один из них ошибочен.

## 5.4 Enneagram: 9 типов личности

`data-section: p5_enneagram_basics`

OCEAN описывает «сколько» каждой черты у персонажа. Enneagram отвечает на другой вопрос: «почему персонаж действует именно так». Если OCEAN — это карта черт, то Enneagram — карта мотиваций.

[VS: E10 — Enneagram × SPINE Mapping. Круг с 9 типами личности, привязанными к SPINE-элементам (Страх → LIE, Желание → WANT, Стресс → FLAW, Рост → NEED). Mini-card показывает тип/страх/желание/LIE/FLAW при hover. Замещает текстовое описание 9 типов как перечисление и даёт визуальный способ исследования маппинга.]

**Enneagram** — модель из 9 типов личности. Используется для выведения SPINE из типа.

### 9 типов Enneagram

| Тип | Название | Альт-название | Ключевой страх | Ключевое желание | LIE (ложная установка) | FLAW из стресса |
|-----|----------|---------------|----------------|------------------|------------------------|------------------|
| **1** | Перфекционист | Реформатор | Быть плохим, коррумпированным | Быть хорошим, цельным | Если я буду идеальным, меня будут любить | Критика себя и других, негибкость |
| **2** | Помощник | Даритель | Быть ненужным, нелюбимым | Быть любимым, нужным | Если я помогаю другим, они не бросят меня | Манипуляция заботой |
| **3** | Достигатель | Деятель | Быть никчёмным, неудачником | Быть ценным, успешным | Моя ценность = мои достижения | Обман ради успеха |
| **4** | Индивидуалист | Романтик | Быть обычным, незначимым | Быть уникальным, аутентичным | Что-то фундаментально отсутствует во мне | Отстранённость |
| **5** | Исследователь | Наблюдатель | Быть некомпетентным, истощённым | Быть компетентным, знающим, независимым | Если я знаю достаточно, я буду в безопасности | Изоляция |
| **6** | Лоялист | Скептик | Быть без поддержки, брошенным | Быть в безопасности, поддержанным | Мир опасен, мне нужен авторитет или система | Тревожное ожидание |
| **7** | Энтузиаст | Эпикуреец | Быть ограниченным, в депривации | Быть удовлетворённым, свободным | Свобода = отсутствие обязательств | Избегание боли |
| **8** | Челленджер | Босс | Быть слабым, уязвимым | Быть сильным, защищённым, влиятельным | Сила = защита, уязвимость = смерть | Доминирование |
| **9** | Миротворец | Медиатор | Быть в конфликте, потерять связь | Быть в мире, цельном, соединённом | Если я не вмешиваюсь, всё будет хорошо | Пассивность |

**RECOMMENDATION:** Столбец «LIE» — справочные данные для понимания типа. LIE и GHOST подробно разобраны в `[ref: part_04.md §4.3 — LIE]`.

## 5.6 Связь инструментов: OCEAN ↔ Enneagram ↔ MBTI

`data-section: p5_cross_instrument_map`

Психологические инструменты **валидировали** SPINE — они не генерируют его. Сначала постройте SPINE-профиль (`[ref: part_04.md §4.1 — SPINE Overview]`), затем проверяйте его консистентность с помощью OCEAN, Enneagram и MBTI. Приведённые ниже таблицы — справочный инструмент для диагностики несоответствий, а не инструкция по созданию SPINE «снизу вверх».

### Enneagram → SPINE: справочная карта

Каждый тип Enneagram имеет предопределённые корреляции с элементами SPINE. Используйте эту таблицу для проверки: если ваш Enneagram-тип указывает на один SPINE-профиль, а фактический SPINE говорит другое — вероятно, допущена ошибка.

| Enneagram элемент | SPINE элемент | Как использовать для валидации |
|-------------------|---------------|--------------------------------|
| Ключевой страх | → LIE (ложная установка, защищающая от страха) — `[ref: part_04.md §4.3 — LIE]` | Если страх = «быть покинутым», а LIE ≠ «меня нельзя любить» → проверьте логику |
| Ключевое желание | → WANT (осознанное желание) | Если желание = «быть нужным», а WANT ≠ «помогать всем» → несоответствие |
| Направление стресса | → FLAW (поведение под стрессом) | Если тип 6 в стрессе → подозрительность, а FLAW ≠ паранойя → ошибка |
| Направление роста | → NEED (потенциал роста) | Если рост = «доверять себе», а NEED ≠ «самостоятельность» → проверьте |

### OCEAN → SPINE: Validation Reference

OCEAN-профиль ограничивает допустимые комбинации SPINE-элементов. Если ваш OCEAN-профиль противоречит SPINE — одна из двух систем содержит ошибку. Используйте таблицу ниже для выявления таких противоречий.

| OCEAN-полюс | Ожидаемый SPINE-паттерн | Признак противоречия |
|-------------|-------------------------|----------------------|
| High Neuroticism (>70) | FLAW связан с эмоциональной реактивностью (тревога, гнев, избегание) | Если FLAW ≠ эмоциональная реакция → проверьте, не занижен ли Neuroticism |
| Low Agreeableness (<30) | FLAW связан с конфликтом, WANT = доминирование или контроль | Если WANT = «помогать другим» при Low A → вероятно, ошибка в OCEAN |
| High Openness (>70) | NEED связан с поиском нового, творчеством, альтернативами | Если NEED = «стабильность и предсказуемость» → противоречие |
| Low Extraversion (<30) | FLAW связан с изоляцией, WANT ≠ «быть в центре внимания» | Если WANT требует социального доминирования → проверьте E |
| High Conscientiousness (>70) | LIE связан с перфекционизмом, «если я буду идеальным, меня будут любить» | Если LIE про «я недостаточно хорош» при Low C → несоответствие |

**RULE:** Принцип валидации: OCEAN и Enneagram **проверяют** SPINE — они не **создают** его. Сначала постройте SPINE по каузальной цепи GHOST→LIE→FLAW→NEED→WANT, затем используйте психологические инструменты для диагностики противоречий. Если инструменты расходятся — перепроверьте SPINE: скорее всего, нарушена каузальная логика.

### Enneagram ↔ MBTI

OCEAN-полюса коррелируют с MBTI-осями. MBTI Composer (M2+) показывает рекомендованные OCEAN-значения для выбранного типа; OCEAN Insight (M2+) прогнозирует вероятные MBTI-типы на основе профиля. Каждый Enneagram-тип имеет вероятные MBTI-типы (и наоборот). Enneagram Builder и MBTI Composer показывают эти подсказки при M2+.

## 5.7 Enneagram Wings (крылья)

`data-section: p5_enneagram_wings`

**Wing** — соседний тип, который модифицирует основное поведение.

### Алгоритм выбора крыла

Каждый эннеаграмм-тип имеет два смежных крыла. Выберите первичное крыло по двум критериям:

| Критерий | Первичное крыло | Вторичное крыло |
|----------|------------------|------------------|
| Функция | Стратегия разрешения базового страха | Вариант совладания со стрессом |
| Пример (Тип 6) | 6w5: Интеллектуализация страха (анализ, подготовка) | 6w7: Активный поиск безопасности (связи, отвлечение) |

Если персонаж реагирует на страх анализом → первичное крыло 5. Если реагирует поиском поддержки → первичное крыло 7.

### Примеры крыльев

| Основной тип | Wing | Разница |
|--------------|------|---------|
| **6w5** | 5 (Исследователь) | Более замкнутый, аналитичный, параноидный |
| **6w7** | 7 (Энтузиаст) | Более активный, реактивный, тревожный |
| **8w7** | 7 (Энтузиаст) | Более харизматичный, экспансивный |
| **8w9** | 9 (Миротворец) | Более спокойный, защитный, "тихий силач" |

## 5.8 OCEAN×Enneagram Matrix + Persona Synthesis

`data-section: p5_cross_matrix`

Матрица показывает корреляцию OCEAN×Enneagram: зелёные ячейки = высокая корреляция, красные = низкая. Нажмите на ячейку для деталей. Автоматическая валидация вашего профиля — **Персона Синтез** ниже.

**Persona Synthesis** — агрегация всех трёх систем (OCEAN + Enneagram + MBTI) в единый профиль с диагностикой консистентности.

**Bridge:** Психологически обоснованный профиль персонажа готов. Но модель не будет автоматически анализировать этот профиль перед ответом — она паттерн-матчит. CoT (цепочка рассуждений) заставляет модель обрабатывать SPINE, OCEAN и Anchors до генерации поведения. → `[ref: part_06.md]`.

### Что вы теперь умеете

- Валидировать SPINE с помощью OCEAN (1–2 экстремальных полюса)
- Использовать Enneagram для проверки LIE, FLAW, WANT, NEED
- Определять wing (крыло) Enneagram и его влияние на SPINE
- Проверять OCEAN×Enneagram кросс-консистентность
- Распознавать OCEAN Value Conflicts при 3+ экстремальных полюсах
